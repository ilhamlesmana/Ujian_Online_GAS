# SPESIFIKASI FUNGSI BACKEND (`code.gs`)

Implementasikan seluruh fungsi backend berikut di `code.gs` dengan pemrosesan cepat (in-memory caching `_cachedSs`, batch `getValues()` / `setValues()`, dan `LockService.getScriptLock()`):

1. **Core & Helper Functions + Hybrid REST API (`doGet` & `doPost`)**:
   - `doGet(e)`: Render `index.html` sebagai SPA dengan viewport mobile-first & `XFrameOptionsMode.ALLOWALL`, atau layani request JSON jika terdapat query `?action=...`.
   - `doPost(e)` & `handleExternalApiRequest_(action, args)`: **Endpoint REST API Hybrid (Bebas CORS)** menggunakan `ContentService.createTextOutput(JSON.stringify(result)).setMimeType(ContentService.MimeType.JSON)` agar `index.html` dapat di-hosting secara mandiri di **Vercel, Netlify, Cloudflare Pages, atau Custom Domain** selain di URL Google Apps Script.
   - `getSpreadsheet_(forceCheckSchema)` & `ensureSheetsExist_(ss)`: Koneksi database otomatis (mendukung `SPREADSHEET_ID` maupun `SpreadsheetApp.getActiveSpreadsheet()`).
   - `normalizeGradeLevel_(rawVal)`: Mengonversi `"Kelas X-IPA-1"`, `"10-A"`, `"XII"`, `"7B"` menjadi tingkat kelas kanonik `"1"` s/d `"12"`.
   - `parseGuruMapelSpec_(specStr)` & `isStudentClassAllowedForMapelSpec_(studentClassRaw, mapelSpecStr)`: Engine pencocokan cerdas yang menentukan apakah seorang siswa di rombel tertentu (misal `10-PPLG-1`) berhak mengakses paket ujian dari guru tertentu.
   - `resolveGoogleDriveMediaUrl_(idOrUrl, type)`: Mengonversi ID atau tautan share Google Drive menjadi direct URL gambar (`lh3.googleusercontent.com/d/<ID>`) atau audio stream.
   - `splitMapelAndJenis_(paketLengkap)`: Memisahkan `"Matematika (Kelas 10) - Ulangan Harian 1"` menjadi `{ mapel_induk, jenis_ujian }`.

2. **Authentication & Profile API**:
   - `loginUser(username, password)`: Autentikasi multi-role otomatis (mengecek `DATA_ADMIN`, `DATA_GURU`, dan `DATA_SISWA`). Mengembalikan role (`admin`, `guru`, atau `siswa`), profil lengkap, daftar mapel/rombel ampuan (untuk guru), dan pengaturan website.
   - `ubahPasswordSiswa(payload)` & `ubahPasswordGuru(payload)`: Validasi password lama dan simpan password baru.

3. **Portal Siswa API**:
   - `getDashboardSiswa(nis, kelasSiswa)`: Mengambil daftar paket ujian yang berstatus `OPEN` dan sesuai dengan kelas/rombel siswa, serta mengecek ujian mana yang sudah dikerjakan beserta riwayat nilai (menghormati flag `tampilkan_nilai`).
   - `getSoalUjian(mataPelajaran)`: Mengambil daftar butir soal untuk ujian aktif. Jika `acak_soal === "YA"`, acak urutan soal dengan Fisher-Yates Shuffle. Jika `acak_jawaban === "YA"`, acak urutan opsi jawaban A–E tanpa merusak pemetaan kunci jawaban! **Jangan kirim `kunci_jawaban` ke client saat ujian berlangsung.**
   - `submitUjian(payload)`: Menggunakan `LockService`. Mencegah double-submit, menghitung skor (`0`–`100`) secara akurat di server berdasarkan kunci jawaban di `BANK_SOAL`, menyimpan rekaman ke `HASIL_UJIAN` beserta JSON `catatan_kecurangan`, mengirim email notifikasi opsional ke guru, dan mengembalikan ringkasan hasil.
   - `getDetailRiwayatUjian(nis, mataPelajaran)`: Mengambil detail pembahasan per butir soal (pertanyaan, jawaban siswa, kunci jawaban yang benar, status benar/salah) hanya jika `tampilkan_nilai === "YA"`.

4. **Portal Guru API (Terisolasi Per Guru)**:
   - `getDashboardGuru(guruUsername)`: Mengambil khusus data milik guru tersebut: daftar `allowed_mapel`, `allowed_rombels`, `master_mapel_guru`, `master_jenis_penilaian` (khusus milik guru tersebut), `bank_soal`, `pengaturan_ujian`, `hasil_ujian`, dan `siswa_ampuan` (daftar seluruh siswa di rombel yang diampu guru tersebut untuk mendeteksi siapa yang **Belum Mengerjakan**).
   - `simpanSoal(payload)` & `simpanSoalBatch(payload)`: Mendukung edit 1 soal maupun **Batch Input / Import puluhan soal sekaligus** dalam satu panggilan `setValues()` cepat, serta otomatis membuat baris di `PENGATURAN_UJIAN` jika paket ujian baru belum terdaftar.
   - `hapusSoal(idSoal, guruUsername)`: Menghapus soal dengan validasi kepemilikan mapel guru.
   - `updatePengaturanUjian(payload)`: Mengubah status `OPEN`/`CLOSE`, durasi menit, acak soal, acak opsi, dan visibilitas nilai.
   - `simpanMasterJenisPenilaian(payload)` & `hapusMasterJenisPenilaian(kodeJenis, guruUsername)`: CRUD jenis penilaian privat milik guru.
   - `hapusHasilUjianSiswa(timestamp, nis, mataPelajaran, guruUsername)`: Fitur **Reset Ujian Siswa** agar siswa yang bermasalah/remedial dapat mengerjakan ujian ulang.

5. **Portal Administrator API**:
   - `getDashboardAdmin()`: Mengambil seluruh data `guru`, `siswa`, `kelas`, `master_mapel`, statistik total, dan `website_settings`.
   - `simpanDataGuru(payload)` & `hapusDataGuru(nip)`: CRUD akun guru lengkap dengan sinkronisasi otomatis ke `MASTER_MAPEL`.
   - `simpanDataMapel(payload)` & `hapusDataMapel(kodeMapel)`: CRUD `MASTER_MAPEL` lengkap dengan pembaruan relasi pada data guru jika label mapel berubah.
   - `simpanDataKelas(payload)` & `hapusDataKelas(kodeKelas)`: CRUD `DATA_KELAS` (Kelas 1 s/d 12) lengkap dengan pembaruan otomatis nama rombel siswa jika nama kelas diubah, serta proteksi hapus jika kelas masih memiliki siswa aktif.
   - `simpanDataSiswa(payload)` & `hapusDataSiswa(nis)`: CRUD akun siswa.
   - `getPengaturanWebsite()` & `simpanPengaturanWebsite(payload)`: Membaca dan menyimpan kustomisasi judul, subtitle, logo (Base64/Drive/URL), dan tema halaman login.

4. **Deteksi Ekstensi AI / Otomasi**: Memindai DOM untuk mendeteksi injeksi ekstensi pihak ketiga yang mencurigakan selama ujian.
5. **Log Pelanggaran Real-Time ke Server**: Setiap pelanggaran menyimpan kategori, deskripsi, detail aksi, waktu kejadian, dan nomor soal yang sedang dibuka, lalu dikirim bersama jawaban siswa saat submit. Di halaman Rekap Nilai Guru, siswa yang melanggar ditandai dengan tombol merah **"<N> Kecurangan (Detail)"** yang membuka modal rincian pelanggaran per poin.
6. **Tombol "Perbarui / Muat Ulang Soal" Saat Ujian Berlangsung**: Memungkinkan siswa memuat koreksi teks soal atau tambahan opsi jawaban dari guru secara live di tengah ujian tanpa kehilangan jawaban yang sudah dipilih maupun sisa waktu timer.

📘 LAMPIRAN PANDUAN INSTALASI & DEPLOYMENT (GOOGLE APPS SCRIPT & VERCEL)
================================================================================

Ikuti 6 langkah mudah berikut untuk menjalankan aplikasi di Google Spreadsheet dan meng-hostingnya di **Vercel**:

1. **Buat Google Spreadsheet Baru**
   - Buka [https://sheets.new](https://sheets.new) menggunakan akun Google Anda.
   - Beri nama file Spreadsheet, misalnya: `DATABASE CBT SEKOLAH DIGITAL`.
   - Salin **ID Spreadsheet** dari URL browser Anda (string panjang di antara `/d/` dan `/edit`).

2. **Buka Editor Google Apps Script**
   - Di menu atas Google Spreadsheet, klik **Ekstensi (Extensions)** -> **Apps Script**.
   - Pada file `Kode.gs` (atau `code.gs`), hapus kode default yang ada, lalu tempelkan seluruh kode **`code.gs`** hasil generate dari **TAHAP 1**.
   - Ganti nilai konstanta `SPREADSHEET_ID` di baris atas dengan ID Spreadsheet Anda (atau biarkan saja karena script otomatis mendeteksi `SpreadsheetApp.getActiveSpreadsheet()`).

3. **Buat File `index.html` (Opsional di Apps Script & Wajib di Folder Vercel)**
   - Di panel kiri Editor Apps Script, klik tombol **`+` (Tambahkan file)** -> pilih **HTML**.
   - Ketik nama file: **`index`** (huruf kecil semua, otomatis menjadi `index.html`).
   - Tempelkan gabungan kode HTML dari **TAHAP 2 + TAHAP 3 + TAHAP 4** secara berurutan ke dalam `index.html`.
   - Tekan `Ctrl + S` untuk menyimpan seluruh proyek.

4. **Generate 10 Tabel Database Otomatis (1x Klik)**
   - Di toolbar atas Editor Apps Script, kembali ke file `code.gs`.
   - Pada dropdown daftar fungsi di sebelah tombol **Jalankan (Run)**, pilih fungsi **`setupDatabaseDanDataAwal`**, lalu klik **Jalankan (Run)**.
   - Saat muncul pop-up izin akses pertama kali, klik **Tinjau Izin (Review Permissions)** -> Pilih Akun Google Anda -> Klik **Lanjutan (Advanced)** -> Klik **Buka ... (tidak aman) / Go to ...** -> Klik **Izinkan (Allow)**.
   - Tunggu beberapa detik hingga muncul log `"SUKSES! Database berhasil dibuat!"`. Sekarang Google Spreadsheet Anda sudah memiliki 10 Sheet lengkap dengan header berwarna dan contoh data awal!

5. **Deploy Backend Google Apps Script Sebagai Web App API**
   - Klik tombol biru **Terapkan (Deploy)** di pojok kanan atas -> pilih **Deployment baru (New deployment)**.
   - Klik ikon roda gigi di samping *Pilih jenis* -> pilih **Aplikasi web (Web app)**.
   - Isi konfigurasi berikut:
     - **Deskripsi**: `CBT Sekolah Digital API V3.0`
     - **Jalankan sebagai (Execute as)**: **Saya (Me)**
     - **Siapa yang memiliki akses (Who has access)**: **Siapa saja (Anyone)** *(Wajib "Anyone" agar Vercel dapat mengakses API Spreadsheet tanpa terblokir login Google)*
   - Klik **Terapkan (Deploy)**, lalu salin **URL Aplikasi Web** yang berakhiran `/exec` (contoh: `https://script.google.com/macros/s/AKfycbx.../exec`).

6. **Hosting Frontend di Vercel (Tanpa Batas Iframe Google & Bisa Pakai Domain Sendiri)**
   - Buka file `index.html` di komputer Anda, cari baris:
     ```javascript
     const GAS_WEB_APP_URL = '';
     ```
   - Tempelkan URL Web App `/exec` dari Langkah 5 ke dalamnya:
     ```javascript
     const GAS_WEB_APP_URL = 'https://script.google.com/macros/s/AKfycbx.../exec';
     ```
   - Pastikan di dalam folder proyek Anda terdapat file `index.html` dan `vercel.json`.
   - **Deploy ke Vercel** (Pilih salah satu cara):
     - **Cara A (Lewat GitHub / Dashboard Vercel)**: Upload folder proyek (`index.html` & `vercel.json`) ke repository GitHub Anda, buka [https://vercel.com/new](https://vercel.com/new), pilih repository tersebut, lalu klik **Deploy**.
     - **Cara B (Lewat Terminal CLI)**: Jalankan perintah `npx vercel --prod` di terminal folder proyek Anda.
   - Selesai! Aplikasi Ujian Online Anda kini live di domain Vercel (`https://nama-sekolah-anda.vercel.app`) dengan fitur **Fullscreen Anti-Cheat Native**, kecepatan CDN global, dan database real-time di Google Spreadsheet!
